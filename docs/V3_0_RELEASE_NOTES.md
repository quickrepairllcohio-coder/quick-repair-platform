# v3.0 Operational Release Notes

This release converts the v2.x feature foundation into a production-oriented release candidate.

### Added
- Technician license/certification registry
- Service compliance requirements by service/state
- Technician service areas
- Compliance-aware dispatch candidate scoring
- Production release health snapshot
- Deterministic unique expense numbering
- Corrected expense creator ownership
- Corrected request-media metadata guard
- Corrected scheduling conflict semantics
- Admin Compliance & Production Health page
- Go-live runbook and production acceptance tests

### Important
The codebase is production-oriented but cannot itself create third-party accounts, accept your legal terms, verify technician documents, provision live payment credentials, or obtain local/state licenses. Those are human/business approvals and must be completed before public launch.
